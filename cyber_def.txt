### 1. General Requirements & Navigation
- The home page and the first/landing page must be the same.
- The main section of the landing page must prominently display: "Welcome to Cyber Crime Reporting".
- Include a persistent navigation menu/sidebar that lists out all pages in the application and explicitly shows the total count of pages available.

### 2. Core Modules & Functionality
- Home Page / Landing Page: Main welcome banner, quick links, emergency helpline numbers, and an overview of features.
- User Complaint / Incident Reporting: 
  - Form allowing users to report cyber crime incidents.
  - File/document upload functionality to attach proofs (e.g., screenshots, PDFs, images).
  - Automated notification system triggered once a user successfully files a complaint, and a feature allowing users to send replies/follow-up messages regarding their case.
- Case Tracking: 
  - Users can enter their unique tracking ID to check the status of their complaint.
  - Interactive Dashboard / Visualizations (Charts & Diagrams):
    - Solved Cases vs. Resolved Cases vs. Pending Cases.
    - State-wise distribution of complaints.
    - Monthly Complaints Trend (Last 12 Months).
    - Resolution Rate Over Time.
    - Average Resolution Time (Days).
    - Crime Type Trends Over Time.
    - Complaints by Crime Type.
    - Suspects by Status.
- Suspect Details (Role-Restricted):
  - A secure page viewable only by specific/authorized users to check suspect details added by the admin.
- Cyber Crime Awareness & Protection:
  - Educational section featuring awareness tips and guides on how people can protect themselves against cyber crimes.

### 3. Technical Stack Suggestions
- Frontend: HTML5, CSS3, JavaScript (or React/Tailwind CSS for a modern UI).
- Backend: Node.js with Express.js (or Python/Django/Flask).
- Database: MongoDB or MySQL to store user data, complaints, file metadata, and tracking states.
- Charts: Chart.js or D3.js for rendering the required diagrams and pie charts.
- Notifications: In-app notification system or simulated email/SMS notifications for case updates and user replies.
